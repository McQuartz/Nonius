# NONIUS

Analyse-Plugin (VST3) für Ableton Live: misst Vocals und Beats an der Stelle in der Kette, an der es sitzt, vergleicht mit einem Ziel (eigene Referenzen) und sagt konkret, was zu tun ist. Verändert den Klang nicht.

Status: Konzept fertig, Phase 0 (Test-Plugin) in Arbeit. Details in `docs/`.
